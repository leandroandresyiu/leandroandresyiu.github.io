Fórmulas

Tocá una fórmula, poné tus números (con prefijos como 4k7 o 100n) y mirá el resultado al instante.

Básicas

Electrónica

Ley de Ohm

V = I · R

Potencia

P = V · I = I² · R = V² / R

Con P e I (o P y V) también sale la resistencia: sirve para saber qué potencia tiene que aguantar un resistor.

Divisor de tensión

Vout = Vin · R2 / (R1 + R2)

Vale sin carga. Si lo que cuelga de la salida consume, la tensión baja: ahí R₂ queda en paralelo con la carga.

Circuito RC

τ = R · C fc = 1 / (2π R C)

Reactancias

XL = 2π f L XC = 1 / (2π f C)

Decibeles

GdB = 20 · log(V2 / V1) = 10 · log(P2 / P1)

−3 dB es una caída de la tensión a 0,707 (la mitad de la potencia): es el punto de corte de un filtro.

Resistencias en serie y en paralelo

Rs = R1 + R2 + … Rp = 1 / (1/R1 + 1/R2 + …)

Divisor de corriente

I1 = I · R2 / (R1 + R2) I2 = I · R1 / (R1 + R2)

Por la rama de menor resistencia pasa más corriente.

Circuito RL

τ = L / R fc = R / (2π L)

Resonancia LC y RLC serie

f0 = 1 / (2π √(L C)) Q = (1/R) √(L/C) BW = f0 / Q

Filtro RC pasabajos a una frecuencia

|H| = 1 / √(1 + (f / fc)²) φ = −arctan(f / fc)

Con f = fc da 0,707 (−3 dB) y −45°.

Impedancia de un RLC serie

Z = R + j (ωL − 1 / ωC) |Z| = √(R² + X²)

Fase positiva: el circuito se comporta como un inductor; negativa: como un capacitor.

Amplificador operacional

Inversor: Av = −Rf / Rin No inversor: Av = 1 + Rf / Rg

Con op-amp ideal. La ganancia real baja cerca del producto ganancia-ancho de banda.

Resistencia para un LED

R = (Vcc − Vf) / I

Caídas típicas: rojo 1,8 V, amarillo y verde 2 V, azul y blanco 3 a 3,3 V. Conviene usar el valor normalizado un poco mayor.

Regulador LM317

Vout = 1,25 · (1 + R2 / R1)

Se desprecia la corriente de ADJ (unos 50 µA). La entrada tiene que estar al menos 2 V por encima de la salida.

555 astable

f = 1,44 / ((R1 + 2 R2) C) D = (R1 + R2) / (R1 + 2 R2)

Con R₁ y R₂ el ciclo de trabajo siempre es mayor que 50 %. Para acercarlo a 50 % se usa R₁ mucho menor que R₂.

Carga de un capacitor

v(t) = V · (1 − e−t / RC) t = −RC · ln(1 − v / V)

A 1 τ llega al 63 %, a 3 τ al 95 % y a 5 τ al 99 %.

Energía almacenada

EC = ½ C V² EL = ½ L I²

Potencia en corriente alterna

S = V · I P = S · cos φ Q = S · sen φ

Frecuencia, período y longitud de onda

T = 1 / f ω = 2π f λ = c / f

En una placa FR-4 la onda viaja más despacio: la longitud de onda es unas 2 veces menor.

Conversor analógico-digital

LSB = Vref / 2n N = ⌊Vin / LSB⌋
